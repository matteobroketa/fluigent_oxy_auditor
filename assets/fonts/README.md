# Bundled fonts

These local webfont subsets are bundled so the application remains offline-capable:

- Inter, Copyright 2020 The Inter Project Authors
- Space Grotesk, Copyright 2018 The Space Grotesk Project Authors
- JetBrains Mono, Copyright 2020 The JetBrains Mono Project Authors

All three families are distributed under the SIL Open Font License 1.1. The
license text is available at <https://openfontlicense.org/open-font-license-official-text/>.
The WOFF2 subsets were obtained from Fontsource and are not loaded from a CDN
at runtime.
